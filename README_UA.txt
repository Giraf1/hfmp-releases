HighFleet MP — тестовий набір для другого гравця (клієнта)
============================================================

Що це: експериментальна DLL, яка під'єднує твою копію HighFleet до гри хоста.
Ти керуєш ворожим кораблем у грі хоста: WASD — рух, миша — приціл, ЛКМ/ПКМ — вогонь
(групи 1/2). Твій корабель у твоїй грі повторює цей корабель, кораблі хоста видно як ворогів.
Шкода рахується в грі хоста; HP твоїх кораблів синхронізується звідти.

Вимоги
- HighFleet у Steam, версія 1.163 (скрипт перевіряє). Steam має бути запущений.
- Мережа між вами: простіше за все спільна VPN-мережа (Tailscale, ZeroTier або Radmin VPN).
  Тоді в хоста буде адреса типу 100.x.y.z (Tailscale) — її й треба вказати.
- Хост має дозволити вхідний UDP-порт 47801 (див. нижче). Тобі нічого відкривати не треба.

Ключ сесії: хост дає тобі слово-ключ (рядок key= у його hfdiag_net.txt). Без однакового ключа
ігри не бачать одна одну - це захист від чужих пакетів.

Встановлення (один раз)
1. Завантаж https://github.com/Giraf1/hfmp-releases (Code -> Download ZIP) і розпакуй куди завгодно.
2. PowerShell у цій папці:
     powershell -ExecutionPolicy Bypass -File setup.ps1 -HostIp <IP хоста> -Key <ключ сесії від хоста>
   Скрипт знайде гру, перевірить версію, зробить ОКРЕМУ копію в
   %USERPROFILE%\HighFleetMP\HighFleet і поставить DLL лише туди.
   Твоя Steam-гра і збереження не змінюються.

Запуск
     powershell -ExecutionPolicy Bypass -File run.ps1
Перед кожним запуском run.ps1 перевіряє https://github.com/Giraf1/hfmp-releases: якщо там новіша DLL,
завантажує її і ставить ЛИШЕ якщо збігається SHA-256 з manifest.json. Без інтернету чи при помилці лишається
поточна DLL (попередження жовтим). Попередня версія зберігається як bass.dll.previous.
Пропустити перевірку: run.ps1 -NoUpdate. Нові версії скриптів (setup/run) так не оновлюються -
про це хост скаже окремо (тоді просто завантаж ZIP знову; setup.ps1 повторно запускати можна).

У головному меню на місці «Титри» — кнопка сутички (Skirmish).
Сутичка → НОВИЙ слот (там усі кораблі доступні й 999999 грошей) → вибери ОДИН корабель → розстановка → старт.
Перед боєм ігри обмінюються кораблями: у тебе ворогом буде корабель хоста, у хоста — твій.
Гра того, хто натиснув старт першим, чекає на завантаженні бою (до 90 с), поки другий теж не почне бій.
Тримай вікно гри активним: WASD — рух, миша — приціл, ЛКМ/ПКМ — вогонь.

Лог (hfdiag.log) під час гри автоматично надсилається хосту (там він пишеться в hfdiag_client.log) —
архіви більше не потрібні. Щоб вимкнути: видали hfdiag_log_stream.txt у папці гри.
Якщо гра не з'єдналась — тоді надішли файл %USERPROFILE%\HighFleetMP\HighFleet\hfdiag.log

Видалення: закрий гру й видали папку %USERPROFILE%\HighFleetMP.

Для хоста
- У лаб-копії хоста має бути hfdiag_net.txt з рядком: bind=0.0.0.0
- Дозволити вхідний UDP 47801 для Highfleet.exe лаб-копії (PowerShell від адміністратора):
  netsh advfirewall firewall add rule name="HighFleet MP host" dir=in action=allow protocol=UDP localport=47801 program="<шлях до лаб-копії>\Highfleet.exe"
- У лаб-копії хоста: hfdiag_ship_net.txt з рядком host.
- Без VPN, через інтернет: потрібен проброс UDP 47801 на роутері хоста.
